SUPPORT WORKFLOW
========================================

ISSUE: Can't start system
1. Check: Python installed?
2. Run: test_api.bat
3. Read: USAGE_GUIDE.txt (troubleshooting)

ISSUE: Integration failed
1. Check: logs/YourEA_timestamp.log
2. Verify: EA compiles originally
3. Read: README.md (troubleshooting)

ISSUE: API connection fails
1. Run: test_api.bat
2. Check: Internet connection
3. Verify: Firewall settings

ISSUE: Integrated EA won't compile
1. Check: RegimeFilterLib.mqh in same folder
2. Verify: MT5 allows WebRequest
3. Read: output/YourEA_README.md

ISSUE: EA won't connect to GUI
1. Start: Python GUI (../CORE_SYSTEM/start_gui.bat)
2. Click: "Start Server"
3. Restart: EA in MT5
