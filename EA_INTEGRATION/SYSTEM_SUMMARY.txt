WHAT IS THIS SYSTEM?
========================================

An AI-powered automation tool that integrates the ML Regime Filter into your MT5 Expert Advisors (EAs) automatically.

NO CODING REQUIRED - Just drop your EA file and get back a fully integrated version in 30-60 seconds!

========================================
HOW IT WORKS
========================================

STEP 1: You Drop EA File
   → Copy your EA (.mq5) to input/ folder

STEP 2: AI Analyzes Code (15-20 sec)
   → NVIDIA Llama 3.1 Nemotron 70B reads your EA
   → Understands structure, functions, variables
   → Plans integration strategy

STEP 3: AI Integrates Code (20-30 sec)
   → Adds library include
   → Adds input parameters
   → Integrates OnInit, OnTick, OnDeinit
   → Adds trade filter checks
   → Preserves ALL your existing code

STEP 4: System Verifies (1-2 sec)
   → 6 automated quality checks
   → Ensures zero compilation errors
   → Validates all integration points

STEP 5: Output Generated
   → Integrated EA saved to output/
   → RegimeFilterLib.mqh copied
   → Complete README.md created
   → Processing log saved

Total Time: 30-60 seconds per EA

✓ DeinitRegimeFilter() in OnDeinit()
✓ Chart display code (optional)

TROUBLESHOOTING
========================================

PROBLEM: Python not found

          Add to PATH during installation

PROBLEM: API connection fails
SOLUTION: Check internet connection
          Run test_api.bat to verify
          Check firewall settings

PROBLEM: Integration fails
SOLUTION: Check logs/ folder for details
          Ensure EA compiles originally
          Verify EA is not encrypted

PROBLEM: EA won't compile
SOLUTION: Ensure RegimeFilterLib.mqh in same folder
          Check MT5 allows WebRequest
          Look for syntax errors in log
