========================================
HOW LOCAL VERSION WORKS
========================================

1. Reads your EA code
2. Finds key patterns:
   - #include statements
   - input parameters
   - OnInit() function
   - OnTick() function
   - Trade opening calls (OrderSend, Buy, Sell)
   - OnDeinit() function

3. Inserts integration code at the right places:
   - Library include after other includes
   - Input parameters in input section
   - InitRegimeFilter() in OnInit()
   - UpdateRegimeFilter() in OnTick()
   - IsTradeAllowed() before trades
   - DeinitRegimeFilter() in OnDeinit()

4. Updates version number

5. Verifies all components added

Total time: 5-10 seconds!
