🎯 HOW IT WORKS:

EA Wants to Start New Grid:
  ↓
Layer 1: ML Regime Filter Check ⭐ NEW!
  "Is this regime safe to trade?"
  "Is direction with the trend?"
  ↓ ALLOWED?
Layer 2: QQE Indicator Check
  "Is trend strong enough?"
  ↓ ALLOWED?
Layer 3: TMA Slope Check (if enabled)
  "Does TMA confirm?"
  ↓ ALLOWED?
Start New Grid ✅

If ANY layer says NO → Grid start is BLOCKED ✗

💡 WHAT GETS FILTERED:

✅ ML Filter CONTROLS:
  • Starting NEW grids (first position)
  • Direction of new grids (BUY vs SELL)

❌ ML Filter DOES NOT Control:
  • Adding levels to existing grid (always allowed)
  • Closing grids (based on profit/loss targets)
  • QQE emergency exits (independent)

Example:
  Grid Active: BUY grid, Level 3
  Price Drops: -100 points (triggers new level)
  Result: Level 4 added WITHOUT filter check ✅
  
  Why? Filter only protects NEW grid starts, not level additions

🔧 TROUBLESHOOTING:

Problem: Chart shows "ML Regime: DISCONNECTED"

  Cause: Python dashboard not running or wrong port
  
  Fix:
    1. Check dashboard is running
    2. Look for: [SERVER] Listening on 127.0.0.1:9090
    3. Check EA parameter: RegimeFilterPort = 9090
    4. Restart EA if needed

Problem: Chart shows "ML Regime: WARMING UP..."

  Cause: Dashboard collecting data
  
  Fix: Wait 10-30 seconds for first regime prediction

Problem: EA not starting grids

  Check MT5 Journal:
    
    "ML Regime Filter BLOCKED..."
      → Dashboard is blocking this regime
      → Solution: Enable regime in dashboard or wait for change
    
    "QQE in neutral zone"
      → QQE not strong enough
      → Solution: Wait for QQE > 55 (BUY) or < 45 (SELL)

Problem: EA starting counter-trend grids

  Cause: Directional filter not enabled
  
  Fix:
    1. Open Python dashboard
    2. Find "Directional Filter" panel
    3. ☑ Enable Directional Filter
    4. ⦿ Select "Strict" mode
