🎯 THE BUG:

  You were RIGHT - regime was changing without market changes!
  
  Root Cause:
    ├─ Auto-refresh recalculates features every 10 seconds
    ├─ Same data + recalculation = tiny floating-point differences  
    ├─ Tiny differences = regime flips randomly ❌
    └─ NOT caused by actual market volatility!

🔧 THE FIX:

  Added prediction caching:
    ├─ predict() now caches result based on buffer size
    ├─ Auto-refresh uses CACHE (no recalculation)
    ├─ Only recalculates when NEW bar arrives
    └─ Regime stays stable between bars ✅
